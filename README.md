# EV Charging Cost Calculator (Python)

A simple Python program to estimate the cost of charging an electric vehicle based on battery capacity, state of charge, and electricity tariff.

## Features
- Calculates required energy for charging
- Estimates charging cost
- Handles invalid inputs
- EV-focused beginner project

## Tech Stack
- Python 3
